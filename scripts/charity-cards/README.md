# Charity cards

`npm run charity-cards` renders one card per charity to `frontend/src/assets/charity/<key>.jpg`
(1200×800): the charity's logo in white on its brand colours, the event, and Shane's part in it.
Edit the `cards` list in `render.mjs` to change the text or colours, then run it again.

| File in `logos/` | Source |
|---|---|
| `special-olympics.svg` | [Logo Special Olympics.svg](https://commons.wikimedia.org/wiki/File:Logo_Special_Olympics.svg), Wikimedia Commons |
| `susan-g-komen.svg` | [Susan G Komen Logo.svg](https://commons.wikimedia.org/wiki/File:Susan_G_Komen_Logo.svg), Wikimedia Commons |
| `habitat-for-humanity.svg` | [Logo Habitat for Humanity.svg](https://commons.wikimedia.org/wiki/File:Logo_Habitat_for_Humanity.svg), Wikimedia Commons |
| `dog-days-rescue-white.png` | Dog Days Rescue's white logo, from [dogdaysrescue.org](https://www.dogdaysrescue.org/) |
| `runner.svg` | Font Awesome "person running" icon (CC BY 4.0), via the site's `react-icons` package |

The logos are the organisations' trademarks, shown to identify the charities Shane supported.
